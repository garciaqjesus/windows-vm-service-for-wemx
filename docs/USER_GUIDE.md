# User Guide (Customer)

Once the VM is marked as **Active**, your connection details will appear in the service page.

## Connect via RDP

1. Open **Remote Desktop Connection** (Windows) or any RDP client (macOS/Linux).
2. Connect using:

   - **IP:** the "Public IP"
   - **Port:** the "RDP Port" (default is 3389)

   Tip: if your RDP client asks for a single host field, use `IP:PORT` when the port is not 3389.

3. Log in with the **Username** and **Password** shown.
4. If the admin added extra instructions, read the **Notes** section.

## Security tips

- Change the password after first login.
- Keep Windows updated.
- If you expose RDP to the internet, use firewall rules, strong passwords, and consider a VPN.
